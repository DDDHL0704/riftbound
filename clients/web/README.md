# 符文战场 Web 对战页

浏览器里的 1v1 对战客户端，直接连接现有服务端 `src/Riftbound.Api` 的 SignalR `/hubs/game`。服务端负责合法性、费用、结算与计分；本客户端只渲染快照，并按提示里服务端给出的 `commandTemplate` 组装玩家意图后提交。

## 运行

先启动内存模式后端（见仓库根 README）：

```sh
ASPNETCORE_ENVIRONMENT=Development ASPNETCORE_URLS=http://127.0.0.1:5088 \
ConnectionStrings__Riftbound="" dotnet run --project src/Riftbound.Api
```

再启动本客户端（端口 5176，处于后端开发环境 CORS 允许的 5173–5179 范围内）：

```sh
cd clients/web
npm install
npm run dev
```

打开 http://127.0.0.1:5176 。双人测试时用两个浏览器（或一个普通窗口加一个无痕窗口）各自登录不同的玩家名。服务器地址可在登录页修改，或用 `?server=` 参数指定。

`npm run dev` / `npm run build` 会先从 `data/official/card-catalog.zh-CN.json` 生成 `public/cards.json`（卡名、费用、效果文本与卡图地址）。

## 已覆盖的对战流程

- 登录（玩家名 + 本地生成的密钥）、快速匹配、创建/加入房间、公开房间列表
- 选择预组卡组、准备；起手调度在桌面中央放大展示，点选要换掉的牌
- 出牌：把手牌拖到桌面上即可打出，拖到战场、基地或单位上会直接作为入场位置或目标；也可以点手牌选「打出」。法力不足时自动横置所需符文（可自动付费的牌由服务端费用预估确认，并带浅金色描边）
- 目标、入场位置、可选附加费用、回收符文补足符能、逐个目标的移动去向、待命费用（单选）
- 移动：点单位后点发光的战场或基地，期间再点其他单位可一起移动；也可以把单位直接拖到战场
- 符文：点选一枚或多枚，选择「横置」「横置并回收」或「回收」；或用右侧的「全部横置」
- 传奇与英雄：放大显示，可用的传奇技能和「打出英雄」以按钮列在旁边
- 待命：自己的待命牌在战场旁显示牌面并带「待命」标记，可点击翻开或从待命打出；对手的待命只显示卡背
- 优先权与法术对决让过、结束回合；「自动让过」在没有任何可响应的牌或技能时自动让过（可关闭）
- 声明战斗（含进攻触发目标与可选费用）、分配战斗伤害、分配技能伤害、触发排序、选择手牌/卡牌、支付费用
- 悬停卡牌显示大图；对手出牌时放大展示；伤害/摧毁/得分浮动提示；卡牌在区域之间移动带过渡动画
- 结算链与目标箭头、废牌堆与放逐区查看、对局记录（合并重复记录）、计分轨、胜负结算
- 每个标签页保存自己的座位，刷新后自动重连；同一浏览器的两个标签页可以分别作为两名玩家

## 界面自动测试

`npm run soak` 用两个相互隔离的无头浏览器上下文完整打若干局，只通过点击页面操作，并在页面提供的操作中随机选择。它会报告三类问题：服务端在等某位玩家行动、页面却没有可用操作（卡住）；服务端拒绝的操作；页面脚本错误。

```sh
npm run soak -- 0-1,2-4 900
```

参数依次为卡组对局（预组卡组序号，`-` 连接双方）和每局操作上限。运行前需启动后端和 `npm run dev`；默认使用系统安装的 Chrome，可用 `CHROME_PATH` 指定其他浏览器。结果和卡住时的截图写入 `soak-results/`，发现问题时退出码为 1。

## 结构

| 路径 | 职责 |
|---|---|
| `src/net/client.ts` | SignalR 连接、身份认证、房间、意图提交与断线重连 |
| `src/game/actions.ts` | 把提示候选转为按卡牌归类的操作，并按命令模板组装命令 |
| `src/ui/Table.tsx` | 对战桌面：交互状态、拖拽、自动付费、选择流程 |
| `src/ui/Zones.tsx` | 计分轨、双方区域（传奇/英雄、基地、符文、牌堆）、战场与待命位 |
| `src/ui/Rail.tsx` | 右侧栏：当前提示与专用面板、卡牌预览、结算链、记录 |
| `src/ui/Overlay.tsx` | 桌面旁的行动按钮、结算链目标箭头、事件提示与对手出牌展示 |
| `scripts/ui-soak.mjs` | 界面自动测试 |

布局参考了 Rift Atlas 模拟器的公开截图（镜像双方、中央战场、侧栏预览与结算链、目标箭头），没有使用其素材或规则。

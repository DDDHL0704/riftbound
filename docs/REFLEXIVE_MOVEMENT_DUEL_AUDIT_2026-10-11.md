# 猛龙摆尾移动与内嵌互斗重审（2026-10-11）

范围：OGN·258/298 的实际移动、移动后内嵌触发、第二目标确认及单位互斗。本批限定范围完整回归通过，不代表整张卡所有组合或官网全量审计完成。

## 来源

中文官网卡图和英文卡库仍呈现旧的简略文本；中文 API 的 errata 字段与 DOC-16 第 4 页勘误一致：先移动一名敌方单位，然后进行一次内嵌触发，在终点选择另一名敌方单位，让两者按自身战力互相造成伤害。已目视核对旧卡图与 PDF 新旧文本对照。

当前核心 355.5.b 明确后续内嵌技能的选择不在原始法术确认时提前作出。387–388 要求内嵌触发使用结算链；技能确认目标及适用费用后可以响应。417.6 及 428.5 规定伤害来源和致命伤害对应的摧毁来源，卡面已经指定是两名单位互相造成伤害，不能把施法者当成两次伤害的控制者。

DOC-09 第 16 页还有远古巨龙关联问答：决斗的友方单位伤害可以利用巨龙，猛龙摆尾的两名敌方单位互斗不可以。来源已核对，但当前巨龙被动和进场行为尚未重建，因此本批不把“放入未生效巨龙后依旧没摧毁”当作 QA 通过。

## 共享实现

法术阶段仅声明第一名敌方单位和精确终点，复用共享移动及装备随行。移动计数、移动触发先正常产生；再建立带有单位对象身份和实际终点的内嵌互斗上下文。第二名敌方单位从终点处筛选，在触发确认时选择，法盾通过共享支付流程处理，可支付或放弃，之后开放响应。

结算时重新检查第二目标的身份、敌方关系和终点范围；不读取新对象的战力。两者当前战力在任一伤害发生前计算，伤害先全部应用，随后通过同一清理批次处理死亡及替换。共享清理新增逐目标来源，包含替换分支，避免把敌方单位造成的死亡归给施法者。凯隐第二次真实移动后，其免伤可在随后的互斗中生效。

回响的两次移动分别产生内嵌触发，可排序并分别确认目标。当前批次验证回响使用同一已声明终点；每次执行独立选择单一终点的协议扩展仍待下一批，不能据此认证全部回响行为。

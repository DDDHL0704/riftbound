# 法盾费用与卡牌费用判定重审（2026-10-09）

后续更新：本记录第 1、2 项开放问题的普通施法路径已在 [施法完成重审](SPELL_COMPLETION_AUDIT_2026-10-09.md) 接续修复；免费重打及其他特殊继续路径仍未闭合。以下保留本批当时证据。

本批替换普通法术及已实现主动技能中“法盾消耗法力”的错误，统一后端预览、支付与提示，并按官方规则纠正拉克丝的费用判定。全部基础规则、卡牌与 QA 的重审仍在进行，不能据此标记最终版 READY。

## 官方依据

本轮重新下载[中国区核心规则 PDF](https://cdn.playloltcg.com/lol/2026/07/2026-07-23/6f47b6ebe57341a5bb5f4bed5548d051.pdf)，SHA-256 为 `d0e36d00c954b9802c7f6e2889124a3cc4f2001a2fb6178d6c54f4ec98e25f64`，与既有官方语料一致。本轮没有重新同步官网全部公告和卡库。

- **809.1.c/c.1/d**：对手的法术或技能每次选择具有法盾的物体，都须支付对应额外符能；可以使用任意特性的符能。法力不能代替符能支付。
- **809.2**：独立来源赋予的法盾值相加，不能仅取最高值。
- **206**：通常判定卡牌费用时，检查印刷或复制后的费用，不受打出时的加费、减费或忽略费用影响。官方明确举例：霹天雳地即使减费，仍可触发拉克丝。
- 拉克丝单位 OGS·006/024、传奇 OGS·021/024 的卡文属于上述卡牌费用判断；失落书库 UNL-211/219 明确检查实际支付的法力，仍保留实际支付语义，不能一并改成印刷费用。

## 本批实现

普通出牌的法盾从法力计算器移出，加入共享任意符能支付。印刷特性符能、回响及其他可选费用继续参与同一资源分配，法力减费不再减掉法盾。相同目标在多次选择中出现时逐次收费。泽拉斯、暗影和绯红之玫瑰已实现的主动技能路径同步改用符能；狂热粉丝确认目标使用同一法盾计算器。

法盾计算汇合目标自身、等级条件、同战场友军和公开友军来源。已支持的独立光环改为累加，并保留正面、在场、控制者和范围条件。提示层删除重复的光环计算，直接调用引擎。旧 `SpellshieldTaxMana`、`spellshieldTaxManaByTargetObjectId` 等运行字段由符能字段替换，不保留旧开发协议别名。

出牌提示为可能需要额外符能的目标开放回收符文/资源支付选项；费用预览与正式提交使用同一支付计划。提示中的资源上限是根据公开对象估算的可选范围，实际选中目标的精确收费仍由后端预览和提交判定。绯红之玫瑰本批验证预先获得符能后的支付；没有扩展其 inline 资源选择。

拉克丝单位及传奇的阈值元数据改为 `MinimumCardMana`，与明确检查实际支付的 `MinimumPaidMana` 区分。高印刷费用法术减费后仍触发；低印刷费用法术不会因法盾或其他支付量增加而变成高费牌。旧测试中与此相反的预期已删除，重复提交、拒绝不变性及恢复/回放断言保留。

## 仍未闭合

1. 本批没有统一拉克丝旧触发的确认/响应时机。仅修正其费用判定，不能登记全部施法触发流程通过。
2. 戏命师的放逐完成路径仍以基础法力检查标为实际支付的阈值；其实际支付、对象归属及继续结算需独立重审。
3. 已支持光环叠加不代表所有法盾赋予来源已实现。扁平标签中的重复授予来源、尚未纳入执行器的装备/临时赋予，以及全部重选目标与技能反制交互仍待检查。
4. 遗弃/月蚀付费回响私密继续、技能目标反制、强买强卖、倒转神通、不能无效化/流转替换、一般触发排序及全部基础规则/QA 继续列为未完成。具体待核反例见 [剩余发现](evidence/ward-2026-10-09/remaining-findings.json)。
5. 本轮没有重启运行服务、替换用户程序或改写用户对局；未打包发布。新版完整双客户端对战及 Windows 实机验收未执行。

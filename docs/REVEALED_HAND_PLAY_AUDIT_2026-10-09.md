# 展示手牌、跨玩家效果出牌与忽略一切费用

本批替换透骨尖钉的旧“提前指定对手手牌、直接移入基地”路径，采用共用效果出牌继续流程。适用范围为下列验证场景，不能外推为全部展示、复制、回响或全部待命规则正确。

## 官方依据

中国区破限勘误（本地 `07.txt` 48–61 行）要求：选择战场，展示一名对手的手牌，由效果控制者选择其中一名单位，再由对手打到指定战场，忽略一切费用，成功打出后眩晕该单位。

破限裁判 FAQ（`06.txt` 773–785 行）明确：手牌中的法盾单位无需支付法盾费用；被要求打出的冷血贵族不需要、也不能摧毁其他单位作为费用。CN 355.10.a 区分非公开区域中的选择与目标，CN 419.3 保留正式出牌流程。来源 URL、原始文件 SHA-256 和文本位置见 [依据](evidence/revealed-hand-2026-10-09/authority.json)；使用已下载并核对哈希的中国区官方语料，没有宣称本批刷新全官网。

## 共用实现

- `RevealedHandPlayContext` 保存展示拥有者、指定战场及物体代次。展示时由施法者选择，选定后切换到手牌拥有者正式出牌；对局原回合玩家不变。
- 展示前不提供对手手牌身份；只在当前展示窗口向玩家及观战快照公开这些身份，牌库等无关信息继续保密。结束展示后，未打出的卡重新按隐藏手牌投影；已看到的信息不会被抹除，但不会因此持续获得后续手牌权限。
- 共用 `IgnoreAllCosts` 与原有“忽略基础费用”区分：免除基础、额外及增费，不提供费用选项，并拒绝伪造的付费意图。原有残酷复活等只免基础费用的行为保留。
- 指定战场许可允许在非己方控制的指定战场出牌，仍遵守“不能打出单位”的场地限制。没有合法目的地时可继续结束效果，不能改打到基地。
- 冷血贵族走正常单位确认，泡泡机等打出技能仍进入可响应结算链。成功入场后只对该单位施加一次眩晕，不给战场本体添加状态。
- 共用单位确认不在父效果未完成时提前启动战场对决，避免重复对决事件。一般多层继续、全部清理时机仍需进一步审计。
- 待命翻开增加可配置的最小目标数和战场目标范围，透骨尖钉必须选择一处真实战场；本批待命案例在已有响应窗口验证，不代表所有待命时机已重审完毕。
- 恢复校验检查展示范围、执行者、费用权限、指定战场和对象代次；观战回放也依据当前展示权限检验身份及隐藏数量。

删除 `PlaysHandTargetToBase` 与 `TryPlayHandCardToBase`，不保留旧协议或旧对局兼容捷径。旧 JSON 场景改为真实战场、明确展示选择、对手 `PLAY_CARD` 和后续法术对决；测试场景结构新增精确区域字段，避免以虚构默认战场替代真实位置。

## 原生客户端

服务器的公开手牌列表接入原生桌面手牌栏，展示期间可查看、点击卡面选择；结束后恢复牌背。原生选择按钮也可完成操作。显示文字明确“已公开展示”“忽略一切费用”“不能支付额外费用”“效果指定战场”，不把公开展示误标为“仅你可见”。费用预览与输入仍由后端裁定。

## 验证与边界

- 18 个规则案例：额外摧毁、印刷符能、法盾单位、选择者/执行者切换、指定战场、隐藏信息窗口、非法命令不改状态、打出技能响应、伪造恢复、费用增加、不可选择急速费用、禁止入场、待命翻开、玩家与观战恢复等。一个案例可覆盖多项断言；用例数不是规则条款覆盖率。
- 274 项相邻重打/待命回归通过；之后补充桌面手牌公开投影、恢复验证与最终交付检查，结果以 [验证清单](evidence/revealed-hand-2026-10-09/validation.json) 为准。
- 两条原生操作链：选择单位后由对手打出、主动放弃；共三条实际按钮命令，序列化恢复与动作日志回放验证。
- 原生桌面另验证公开窗口显示两张可见卡对象（部分图像在独立测试中为文字占位）、关闭窗口恢复一个隐藏手牌堆；截图和机器断言一并保存。本批是受控快照与生产控件测试，没有声称完成双客户端联网自然对局或 Windows 实机验收。
- 规则快速档已加入 `UnitRevival` / `RevealedHand`，避免今后执行 `focus recast` 漏掉这些新家族。完整矩阵只在这次交付边界运行，原生显示缺口导致的一次中断记录不计作通过。

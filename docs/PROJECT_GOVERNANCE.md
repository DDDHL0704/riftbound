## 产物与Git

Git保存源码/测试、简短台账、来源引用/哈希和可取回产物runID/路径/结果；新大日志、TRX、SQL输出、二进制放CI artifacts或已忽略var/qa。哈希不能替代可访问原件。旧已提交证据、来源快照、必要fixture、原始数据库及有用失败原件保留，不重写历史或批量清除。在途批次安全收尾，不为新政策重跑/重包装。

候选证据保存策略：普通CI产物现配置7天，仅短期诊断；新工作流将每周/手动L3产物设90天（远端实际保留上限和到期日须在首个完成run核实），且在到期前保存到持久发布产物或受管本地候选目录并记录可取回位置。当前尚未实现到期前自动持久转存/实际到期校验，不声称已有长期归档；失效链接对应证据标待补，不能只保留哈希认证。不得把大原件重新塞回Git解决保留问题。

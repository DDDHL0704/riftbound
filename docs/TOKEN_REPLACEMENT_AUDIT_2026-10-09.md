# 可恢复的指示物替换与入场属性重审

本批实现基兰“时间法师”的可选替换基础流程，并适配通用创建路径；不代表所有指示物来源或整张卡所有交互已完成。

## 官方依据

中国区核心规则 143.4、184.1、370.3、371–375，官方基兰卡面及裁判 QA：一次镜花水月在一个/两个基兰都生效时，分别产生两个/三个活跃映像，全部继承关联复制与瞬息。沿用本地官方资料，没有重新同步全站。来源和哈希见 [authority.json](evidence/token-replacement-2026-10-09/authority.json)。

## 共用流程与覆盖

- `TokenEntryPlan` 保存待创建批次、当前指示物序号和已应用来源的对象代次。替换选择期间不创建指示物、不完成父法术，也不开放新的响应；继续结算复用既有 `CHOOSE_CARDS`、原父项目和服务器提示。
- 玩家逐一决定来源顺序。每个基兰最多增加一名复制体；两个基兰对应三个映像，不能机械翻倍为四个。不选会跳过当前指示物的剩余可选替换，不消耗未使用来源的回合次数；同批次下一个指示物仍可使用。
- 次数记录绑定来源对象并在回合结束清除；来源必须由出牌者控制、公开且确实位于战场，基地、隐藏、对手来源、缺少实际战场定位均不能替换。
- 新增映像与原映像共用关联内嵌复制上下文，复制前均为活跃 0 战力，复制后全部获得瞬息。每个新单位分别产生进场事件，所以分别触发薇古丝。
- 回响保存已完成执行序号，第二段暂停后不会重做第一段。选择 ID 包含执行序号；恢复校验拒绝伪造数量、重复来源、不匹配来源、缺失选择和非法继续位置。
- 删除 `ResolvePassPriority` 内部提前发布单个触发的重复逻辑。统一在事件、内嵌触发与清理观察者完成收集后发布，保留跨暂停的触发队列，随后排序/响应。

本批接入的创建入口是 `CreatedBaseUnitTokenCount` 描述的通用法术/打出技能、`CreateBaseUnitTokensFromTrigger` 对应的绝念，以及据守的 `MINION` / `ROBOT`。它们按同一批次的指示物配方追加实例，复用原有工厂、入场调整和进场观察者。没有为每一张牌另写翻倍函数。

## 同时修复的旧错误

通用创建函数原来用效果标签覆盖工厂标签，可能丢失单位类型、机器人“机械”、战鹰“鸟类”或原有关键词；现改为保留工厂标签并合入效果调整。

通用法术/打出技能的指示物入场状态改用 `CreatedBaseUnitTokenEntersReady`。默认休眠，官方明确活跃的精灵及映像来源显式配置；绝念采用指定入场状态，未指定则休眠。额外复制体自动继承相同状态。既有全局工厂 API 和其他独立创建入口没有被假定全部正确。

官方目录中的 OGN·274/298 未列仙灵属性，UNL·T07 列有；本批按实际选择的工厂保留特质，不混入另一个版本的属性。生成来源选择哪一版同名指示物仍需后续核对，不能用通过的旧工厂测试代替该核对。

原生确认摘要显示“应用替换、多打出一个复制体”或“跳过、保留未使用的回合次数”，玩家可选择第二个来源先应用。

## 验证

新增 22 个规则/继续结算案例。最终 `check` 9008/9008 通过，测试耗时 72.05 秒，含构建和发现共 76.92 秒。定向完整对局 3/3：牧魂人指示物光环、乐芙兰映像、法盾与绝念联动，均包含分数胜利及动作回放。

首次批次 `check` 8993 通过、12 失败，均为受影响旧指示物预期；修正为默认休眠和保留实际工厂特质。第一次修订把 UNL 精灵属性误放入 OGN 工厂预期，聚焦测试暴露后重新核对官方目录并改正，未削弱断言或跳过测试。

Godot 构建零警告零错误。原生证明使用真实后端 prompt、生产 `PromptInteractionController` / `ActionBar` 按钮及命令模板，输出接受/跳过两条命令；两条命令实际送入 `MatchSession`，逐步序列化恢复及动作/事件回放均一致。此项为 headless 控件证明，不是人工画面或双客户端自然对局验收。

上一批 f9414f12 的 CI 37913931575 已完整成功，包括规则全量、连接恢复及 macOS/Windows 打包。当前批次 CI 状态与本地结果分别记录。精确命令、输出、计数及回放哈希见 [validation.json](evidence/token-replacement-2026-10-09/validation.json)。

## 剩余范围与下一批

1. 乐芙兰和传奇启动、部分征服/移动/开始阶段等独立指示物创建路径尚未全部接入可选替换。下一批应将它们的费用、来源/位置捕获及关联创建统一迁入可恢复流程，不能只在最终事件后补出复制体。
2. “在此处”、可选择基地/控制战场及待命来源的位置传递仍需继续核对；通用创建的旧基地路径不等于全部合法目的地已实现。
3. 护驾的可选黄色符能活跃调整、同名指示物不同版本属性，以及其他种类替换的混合顺序未验收。
4. 其他眩晕观察者和任意局部复制层仍未完成。当前用户对局/运行服务未重启，当前开发源码不兼容旧开发存档；Windows 实机、人工视觉和新的两客户端对局需独立验收。

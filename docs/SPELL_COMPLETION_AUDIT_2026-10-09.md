# 法术打出完成、触发确认与关联放逐重审

后续更新：菲兹／卡莎废牌区法术重打已在 [效果重打审计](EFFECT_RECAST_AUDIT_2026-10-09.md) 接续替换，并验证卡莎、戏命师与回响的已列 QA。其他效果出牌及旧恢复格式仍待审计；以下保留本批当时结论。

本批重写正常施法及已覆盖继续流程中的施法触发。历史绿色测试曾把“提交法术后立即加战力／抽牌”当作正确行为，本批按中国区规则纠正这些预期。此记录不代表全部基础规则、卡牌或 QA 已完成。

## 官方依据

- 核心 CN 419.4.a / 419.4.a.1：以卡牌打出为条件的触发式技能，在卡牌效果结算使打出动作完成时触发；被无效化的卡牌不产生此类触发。CN 419.4.b 的非触发式检查仍按确认记录，两者不能混用。
- CN 419.3.b：效果要求打出卡牌也必须执行正常打出步骤。直接调用效果的旧“免费施法”不是合格替代。
- CN 190.6：战场明确指示施法玩家执行的技能，由该玩家控制；不应附加战场必须由自己控制的限制。
- 起源勘误中的幻梦之树改为“玩家将此处的一名友方单位选为法术目标时”。这是选目标事件，不能等待法术结算完成；起源裁判 QA 也明确任何玩家、无人控制战场均可触发。
- 破限裁判 QA：时间扭曲已自行放逐后，不再被戏命师放逐；被无效化的火箭轰击不触发戏命师。卡莎重打法术与回响的回收优先案例仍待完整新流程验收。
- CN 206 及卡文费用阈值：印刷／复制后的卡牌法力和实际支付法力分开记录，不能互相替代。

原始官方 URL、文件日期、SHA-256 和本地路径见 [authority.json](evidence/spell-completion-2026-10-09/authority.json)。本批核对了已有官方语料，未重新同步全部官网文件。

## 实现边界

| 共享机制 | 已接入的行为 |
|---|---|
| `CardPlayCostReceipt` | 一次确认出牌记录卡牌法力及实际支付法力；回响内部执行不复制付款记录 |
| 完成事件入口 | 效果真正完成后捕获来源，再进行状态清理；私密洞察未结束时不提前触发；被无效化不触发 |
| `SpellTriggerContext` | 保存触发种类、来源物体代次、已玩法术、拥有者、费用及实际战场身份，供排队、确认、响应和恢复共同使用 |
| 元数据分派 | 拉文布鲁姆学生、黛安娜单位、拉克丝单位／传奇、戏命师、战场施法技能共用流程；失落书库从同一完成边界建立洞察触发 |
| 可选触发确认 | 废弃大厅选此处友方单位或放弃；戏命师选择放逐刚结算法术或放弃；确认后双方仍可响应 |
| 关联放逐账本 | 按技能来源代次和控制者隔离记录；失效卡牌代次不计数；集齐四张归还各自拥有者废牌区，召出四符文并抽牌 |
| 选目标事件 | 幻梦之树按勘误在确认目标后触发，按玩家／战场限制每回合一次，支持对方控制及无人控制的实际战场 |

删除了分散的立即加战力、立即抽牌、战场自动选目标，以及戏命师旧标签累计／直接拦截结算的分支。本批没有增加历史对局迁移或兼容回退。新版本仍保留保存恢复与命令事件回放验证。

同一行为不能只看卡名或源码方法名是否存在。四项源码字符串检查已由执行行为替代，见 [退役记录](evidence/spell-completion-2026-10-09/retired-source-checks.json)。两项错误的“对方控制战场就跳过”预期，替换为真实战场、双方和无人控制的测试，见 [预期更正](evidence/spell-completion-2026-10-09/retired-behavior-expectations.json)。

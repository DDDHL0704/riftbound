# Plan B / B3 Unit Conquest Trigger Spec Evidence

Date: 2026-06-29

Project status: **NOT READY**.

2026-06-30 follow-up: Vayne pay-return pending-payment reason parsing and runtime trigger/reason payloads now validate through `UnitConquestTriggerSpecRules.TryGetTriggerByEffectKind(...)` plus `IsUnitConquestPayReturnSelfToHandTrigger(...)`. `CoreRuleEngine` no longer owns `UnitConquestPayReturnSelfToHandEffectKind`; the wire-compatible `UNIT_CONQUEST_PAY_1_RETURN_SELF_TO_HAND` payload remains unchanged.

2026-07-01 follow-up: unit-conquest runtime routing no longer exposes or calls public `TryGetUnitConquest*` helper methods. `CoreRuleEngine` enumerates `UnitConquestTriggerSpecRules.TriggersForCard(...)`, filters auto-resolvable effects with `IsSupportedUnitConquestTrigger(...)`, and uses the same generic `TryGetTrigger(...)` / `TryGetTriggerByEffectKind(...)` path for Vayne pay-return payment validation.

2026-07-03 follow-up: OGN Kai'Sa's graveyard spell conquest text now parses to `UNIT_CONQUEST_PLAY_LOW_COST_GRAVEYARD_SPELL_RECYCLE` and has natural-conquest plus B0 official-deck-derived runtime representatives for the no-target draw-spell path. The execution bridge now also admits no-target rune-call spells through the same shared free-play/recycle predicate; official `OGN·134/298` 动员 covers both successful rune-call and failed-rune-call draw fallback natural-conquest paths. The bridge remains intentionally limited to no-target spell shapes that can reuse existing stack resolution without extra target, power-cost prompt, experience, pending-payment, token-state handoff, or source-zone replacement. The B0 route still uses a legal Kai'Sa red/blue deck and official `UNL-061/219` 台前作秀 as the controlled low-cost graveyard draw spell, then continues through score victory and action-log replay. Complete optional choice prompts, power-cost UI, targeted spells, and full official Kai'Sa breadth remain open.

2026-07-03 follow-up: SFD Rumble's conquest text now parses to `UNIT_CONQUEST_RECYCLE_FRIENDLY_PLAY_GRAVEYARD_MECHANICAL_UNIT` and has natural-conquest runtime representatives for both zero-mana-after-reduction and non-zero reduced-mana trigger-payment paths. The execution bridge recycles one other controlled public field unit to the owner's main deck, then plays one controlled graveyard `机械` unit to base when the recycled unit's power reduces that unit's mana cost to 0; when a reduced mana cost remains, it opens the existing `TRIGGER_PAYMENT` / `PAY_COST` window, accepts `SPEND_MANA:<reducedCost>` before moving zones, declines without recycling or playing the graveyard unit, and rejects insufficient mana while preserving the payment window and both target zones. Both the successful non-zero reduced-mana payment path and the insufficient-payment no-mutation path now have B0 official-deck-derived midgame representatives that start from legal Rumble deck submission/opening, continue through score victory, and replay the post-midgame action log to the same final state hash. Complete optional target choice prompts, explicit target selection, battlefield destination choice, and full official Rumble breadth remain open.

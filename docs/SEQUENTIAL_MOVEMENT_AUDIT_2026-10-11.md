# 虚空来袭顺序移动重审（2026-10-11）

范围：UNL-202/219 虚空来袭的两条移动指令、独立终点、回响和进攻方判定。限定范围验证通过，全量官网卡牌与规则审计仍未完成。

## 官方依据与实现

官网中英文正文均为先移动一名友方单位，再移动一名敌方单位。当前核心 355.4、355.4.a 要求为每次移动声明合法且不同于当前位置的终点；359.3.e.5 允许其余合法指示继续执行。实现改为共享有序移动计划，保留目标索引，即使第一目标失效也不会把第二终点错误赋给第一目标。每条指令独立产生移动事件，移动执行者均为法术控制者。

终点可以是相应单位控制者的基地或实际战场。协议、严格 JSON 映射、费用预览、结算链、恢复及逐次回响均保留独立终点；拒绝缺失、额外或错误类型的计划。原生生产 PlayCardOverlay 提供按顺序选择终点的控件，回响可以重新选择目标与终点。装备随行、移动禁止、目标代际和再次打出复用共享规则。

两名单位进入同一未受己方控制战场的测试实际完成法术对决，再声明战斗，检查施放者为进攻方；没有以仅检查事件名称代替战斗角色验证。独立移动导致沃利贝尔观察者分别触发，已通过两条指令的测试。

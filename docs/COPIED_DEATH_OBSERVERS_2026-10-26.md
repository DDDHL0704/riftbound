## 行为和验证边界

捕获时枚举有效独立文本实例，记录原单位代际和附加文本来源版本。每份文本独立触发、排序、响应和结算；首次同时死亡按每份文本独立选择发生项，死亡台账仍按实际死亡计数。已获得技能不因卸除或来源离场而撤销，后续事件使用届时有效文本，旧自指技能不作用于新代际。

权威状态保留原绑定；公开死亡事实保留既有四字段形状，不发布附加文本私有绑定。来源进入私有区域后，公开队列/堆栈隐藏当前对象 ID，保留公开技能打印/效果。当前版本恢复严格核对来源、代际、版本、时间和公开视图；协调伪造当前状态和视图仍必须通过原接受日志重建，不能仅靠结构验证放行。

新增 `CopiedDeathObserverTests` 覆盖四族、零/一/两份复制、同时死亡和独立首次选择、真实卸除、真实返回手牌、来源同动作死亡、随从排除、控制者/所有者区别、资源子死亡时钟、绑定篡改及玩家/观战隐私。显式中局和组件续体在测试中标明；不把它们称为普通空房开局或完整对局验收。

`CopiedDeathObserverRegistryTests` 使用实际装配和死亡命令。其受控中局由日志中的 DEV 命令建立，冷 JSON registry 重放原下一命令并逐项比较状态与事件；重复命令不追加日志。协调伪造复制触发的死亡对象时，结构可合法，但原日志审计拒绝，两次加载不缓存；修复存储后第三次可加载。原事件/命令和严格恢复入口保持不变。

本地可取回原件位于开发工作树的 `var/qa/copied-death-observers-20261026/`：`source/receipts.json`、`source/gameplay-comparison.json`、各唯一批次的源清单/补丁、编译输入、TRX、日志、运行模块身份及反例程序集。最终固定提交及 L1 结果由独立 delivery JSON 记录；这些本地结果不替代最新合并输入 L2，也不替代固定 main 的 L3 SQL/SignalR/真实重启验收。

# Triage Labels

| Canonical role | Tracker label | Meaning |
|---|---|---|
| needs-triage | needs-triage | Maintainer evaluation |
| needs-info | needs-info | Await reporter information |
| ready-for-agent | ready-for-agent | Specified and ready for an agent |
| ready-for-human | ready-for-human | Requires human implementation or judgment |
| wontfix | wontfix | Will not be actioned |

Categories remain bug / enhancement. Use exactly one category and one state; flag conflicting states before action.

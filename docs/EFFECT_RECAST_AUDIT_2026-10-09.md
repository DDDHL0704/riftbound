# 效果中重打法术、费用与回收重审

后续：兰博回收费用与机械单位重打已继续重审，当前范围与证据见 [后续批次](MECHANICAL_RECAST_AUDIT_2026-10-09.md)。下文保留本批历史边界。

本批将菲兹和卡莎的废牌区法术重打接入共享的效果中出牌流程，删除旧的自动选第一张牌、代选目标、限制“代表性法术”后直接调用效果的实现。覆盖这些来源和已测试继续路径，不代表全部效果出牌、全部基础规则或 QA 已完成。

## 官方依据

- CN 419.3.b：效果中打出仍须执行正常打出步骤，除非效果另有说明。
- CN 419.3.c：没有符合条件的卡牌时，不执行打出，继续结算。
- CN 419.4.a：一般施法触发在打出完成后触发；无效化不触发一般的“打出法术”技能。这与来源指定的后续回收指示不同。
- CN 359.3.e.14 / 124.1：关联指示与跨区域物体状态处理。本批将来源要求的回收附于该次打出的结算项目，并在离链后执行，保留拥有者与新的物体代次。
- CN 383.4.c：征服技能进入结算链；不能在征服函数内直接执行所选法术。
- 中国区破限裁判 QA：菲兹重打闪现、卡莎重打顺劈，被蔑视无效化后仍回收；卡莎回响打出火箭轰击后回收，不被戏命师放逐。
- 卡文：菲兹允许法力费用不高于 3；卡莎要求低于当前分数。两者只免基础法力，符能及额外费用仍需支付。

原始官方 URL、文件日期、SHA-256、条款和 QA 位置见 [authority.json](evidence/effect-recast-2026-10-09/authority.json)。本批核对已有中国区官方语料，未重新同步全部官网文件。

## 共用实现

| 机制 | 改动与约束 |
|---|---|
| 效果中正式出牌 | 扩展现有 `PendingEffectPlayState`，使用同一套出牌提示、费用预览、目标、模式、回响和支付校验；不再增加独立的“免费施法执行器” |
| 来源资格 | 按技能元数据判断费用阈值；来源必须仍在允许的区域、代次一致，卡莎按当前分数再次校验；不硬编码卡号清单 |
| 玩家选择 | 有合格来源时可选牌或放弃；没有合格来源则自动继续。多个合法目标不会导致跳过技能，也不会由后端擅自选择 |
| 响应时序 | 菲兹打出技能、卡莎征服技能先响应；选择并确认重打法术后，双方可再次响应该法术 |
| 回收指示 | `AfterPlayRecycleInstruction` 绑定该次打出；正常完成、回响完成及无效化离链共用回收入口；按拥有者归还牌库并重置离场状态 |
| 完成观察者 | 回收完成后才建立一般施法触发；实际支付的回响费用仍计入费用记录，戏命师不会放逐已按来源指示回收的卡 |
| 私密继续与恢复 | 月蚀的洞察选择结束前不提前回收或清理致命单位；来源随后死亡不抹去已确认的回收指示；恢复验证检查来源、上下文和代次 |
| 原生客户端 | 继续使用生产 `PlayCardOverlay`、服务器费用预览及 `ActionBar`；放弃按钮明确显示“放弃再次打出”，不让客户端计算规则 |

本批 `CoreRuleEngine.cs` 相比本批起点删除 667 行、增加 10 行；新共用模块及其他修改另计。这是当前脏工作区内本批前后比较，不是相对 Git HEAD 的统计。删除了旧的 `TryResolveGraveyardSpellFreePlayRecycleTrigger`、第一张牌选择器、代表性法术／目标筛选、即时执行及重复回收函数。未新增旧对局迁移、旧格式回退或兼容分支。

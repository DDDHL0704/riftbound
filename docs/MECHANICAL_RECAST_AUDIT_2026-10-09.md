# 回收单位费用与机械单位再次打出重审

兰博（SFD·026/221、SFD·026a/221）的征服能力已接入共用效果中出牌流程。旧的自动选择第一名友方单位和第一张废牌区机械单位、仅支付法力、直接移入基地的路径已删除。本批覆盖该技能家族及下述测试；不代表所有效果出牌、全部基础规则或 QA 完成。

## 中国区官方依据

- 破限勘误明确来源是“你的废牌堆”；不能从对手废牌堆选择机械单位。
- 铸魂淬炼官方 FAQ 明确可回收机器人指示物：回收后立即消失，但仍可使用其离场前战力。
- CN 203.1–3、355.10.c.1：回收是“执行 X，以此执行 Y”中的费用，不是选取法术目标；不能支付费用就不能执行关联效果。
- CN 359.3.e.14：先执行前置关联指示；已支付的回收不是后续出牌失败时自动退款的事务。
- CN 383.4.c、419.3.b–c：征服技能进入结算链；效果中打出仍使用普通出牌步骤，无合格牌时跳过打出并继续。
- 减费只减少法力。符能和其他适用的费用仍使用正常费用引擎计算与校验。

[authority.json](evidence/mechanical-recast-2026-10-09/authority.json) 保存官方 URL、SHA-256 和文本位置。本批核对已下载中国区官方语料的哈希；网页工具无法打开两份官方 PDF，不声称本批重新同步全部官网资料。

## 共用实现和清理

| 环节 | 当前行为 |
|---|---|
| 征服触发 | 沿用共享捕获上下文、真实战场定位、排序和响应；已验证普通兰博来源离场后，已产生的技能仍继续 |
| 回收费用选择 | 服务器列出其他友方场上单位，允许选择或放弃；不自动选择，不对费用对象收取法盾目标费用 |
| 区域和战力 | 沿用拥有者牌库目的地、装备脱离和指示物离场原语；`RecycledUnitReceipt` 保存物体代次和包含当前连续效果的离场前战力 |
| 再次打出 | `PendingEffectPlayState` 保存自己的废牌区合法机械单位、来源代次、法力减费和父技能；共用选牌、目标、费用预览、支付与确认 |
| 失败与继续 | 支付回收后不再把“放弃支付”回滚为单位留场；出牌失败不扣后续费用，保留已支付回收。无合格牌自动继续；资源确实无法支付时可继续结束效果 |
| 打出技能 | 正式单位确认后仍产生可响应的打出技能；测试由泡泡机选择目标并在响应后将目标变为活跃 |
| 恢复与界面 | 校验选择窗口的父技能、执行者、合法对象，以及减费记录和费用策略；客户端摘要明确“支付回收费用”或“放弃回收与再次打出” |

`CoreRuleEngine.cs` 相比本批起点删除 **763 行**、增加 **1 行**；新共享模块和其他文件另计。这是本批前后比较，不是相对 Git HEAD 的统计。10 个旧专用函数、两处旧支付分派、即时征服分支已删除；没有增加旧对局兼容或旧支付格式回退。详见 [退役实现](evidence/mechanical-recast-2026-10-09/retired-implementation.json)。

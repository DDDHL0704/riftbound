# ADR 0004：缺席传奇与选定英雄的共享开局流程

2026-11-02，已接受。依据中国区官方《赛事规则》602.4.a.5–5.b 和核心规则 315.1–315.3：现开卡组可以没有传奇或选定英雄；缺少任一者时，在每局本人首个回合的开始阶段补抽一张，两者都缺也只补一张。

共享正式开局按已通过格式校验的卡组蓝图创建物体。空的传奇／选定英雄编号不创建物体，对应区域保持空；选定英雄存在时才从主牌堆移出其实体。战场、起手牌、符文洗牌及其随机游标保持原流程。`ChosenChampionRules` 在没有选定英雄时不将其他英雄单位认作选定英雄。

开局为缺少任一角色的玩家记录私有 `MatchState.OpeningRoleDrawPendingPlayerIds`。该字段省略空值，不进入玩家或观战快照、提示和公开事件；双方角色齐全时保留原有状态序列化形式。本人首次进入开始步骤时，移除自己的待处理记录，并走共享抽牌流程补抽一张，随后继续回合开始触发与得分步骤。此补抽在召出和常规抽牌阶段之前，所以跳过抽牌阶段的效果不会跳过它。共享抽牌账本、抽牌触发、燃尽、胜负和物体区域均随之更新。

以玩家身份记录待处理动作，避免额外回合改变另一名玩家的首回合编号。换局时由正式开局重新生成这份记录。它随权威帧序列化、哈希、恢复和动作回放；恢复检查拒绝重复玩家、未入座玩家和卡组角色齐全的玩家出现在记录中。角色缺席根据卡组蓝图判断，游戏中传奇离场或英雄区变空不会新增补抽。

恢复中的卡组字段允许规范化后的空字符串，非空编号保留原有结构校验。卡组是否合法仍由格式校验器决定；本改动不改变构筑赛卡组校验或公开建房入口。测试从显式已接纳的卡组蓝图验证共享开局、冷恢复及精确初始状态回放；生产的空房间起点检查保持不变，现开卡池准入、可空 `SUBMIT_DECK` 路由与完整房间回放仍由房间接入步骤补齐。

SFD·190–192 的官方“唯我”提示文本为“你的卡组中只能拥有一张同名的此牌”。602.4.a.6.a 的豁免在现开卡组准入时处理；共享打出流程可接纳已经合法入组的多个实体。三个印次各验证两张独立副本先后支付、打出、进入基地、冷恢复与精确初始状态重放，保留两个物体身份；SFD·192 的打出触发经过双方响应后结算。补充 SFD·079 巴德在无传奇时不支付可选传奇费用的打出，以及 SFD·210 传奇殿堂在无传奇时征服且不产生无法支付窗口的验证，均含冷恢复和精确初始状态重放。这些来自显式中盘状态，不表示现开房间准入或完整对局已接通。

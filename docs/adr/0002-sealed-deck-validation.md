# ADR 0002：现开校验的权威卡池与空白战场

2026-11-02，已接受。中国区[赛事规则](https://cdn.playloltcg.com/lol/2026/10/2026-10-10/0d5c26b5535345d48e1afafb3e2a0018.pdf) 602.1.a.1–3、602.1.b、602.3.d–g、602.4.a.2–6；[核心规则](https://cdn.playloltcg.com/lol/2026/10/2026-10-10/a21ead876c6b44d6abe386b6ae54ea28.pdf) 103.3、103.3.d.2。

`OfficialDeckValidator.Validate(deck, catalog, OfficialDeckFormat.Sealed, sealedContext)` 复用已有主牌与战场牌类检查。`SealedDeckValidationContext { Pool, BestOf }` 必须由房间根据该玩家已持久化的服务端卡池生成；它不是客户端提交字段。缺失上下文或非法卡池计数时拒绝。房间接入前，现开格式不能通过没有上下文的现有提交入口。构筑调用和既有默认参数保留原行为。

后续接入房间时，须同时更新提交命令的 canonical raw 校验及恢复校验，使空传奇／英雄通过协议层，再由格式对应的卡组规则裁定；当前协议层仍要求非空，空缺角色的开局流程也由后续步骤处理。

校验按真实 cardNo 计数：主牌中的选定英雄只计一次，传奇在主牌外另计一次；基础符文和空白战场不消耗卡池。主牌至少 25 张，符文恰好 12 张，符文只允许六种无规则文本的基础符文；任意系列及异画基础符文均可使用。实际使用的传奇、主牌、符文和战场特性取并集，最多三种；包含多特性的专属法术时必须将其全部特性计入。传奇／选定英雄可缺席、彼此无需相同英雄标签。同名、唯我和专属卡牌数量限制豁免；构筑禁卡不套用。

602.4.a.3.b 明确的是“专属法术”英雄标签豁免；专属装备及专属单位当前沿用核心 103.3.d.2，需要对应传奇。它们的数量限制仍豁免。是否官方意图也豁免其他专属牌型，已在 BACKLOG 标待确认，不扩大条文例外。

`SEALED·BLANK-BATTLEFIELD` 与前端契约一致，只在现开卡组校验中解释。它不是官方目录印次：物体工厂可创建和恢复这种无规则文本、无初始控制者的实体战场对象；征服、控制与计分复用普通战场流程。单局制提交 3 张，三局两胜每局提交 1 张，可重复空白；实体战场可按卡池持有数量提交同名副本。同轮耗用与平局复用由后续局间流程管理。

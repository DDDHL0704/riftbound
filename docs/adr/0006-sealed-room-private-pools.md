# ADR 0006：现开房间的私有卡池

2026-11-02，依据中国区[赛事规则](https://cdn.playloltcg.com/lol/2026/10/2026-10-10/0d5c26b5535345d48e1afafb3e2a0018.pdf) 602.1.a.1、602.3.d–e、602.4.a.1–6、602.4.b.2.a。每名玩家的六包由服务端在真实入座事务中生成，和席位一起提交到私有权威日志。写入失败不安装席位或卡池；同一玩家重复入座不重新生成。同步入座入口在现开房间转用相同事务流程。

房间配置使用 `MatchSessionOptions.ForSealed(setCode, bestOf)`，只接受统一配置中已开放的系列及 1／3 局制，并强制关闭无卡组准备、隐藏提交牌面。房间私有开局种子通过 HMAC-SHA256 的独立域、系列和固定席位派生各玩家种子；独立于对局洗牌消耗顺序，也不受玩家昵称影响。`PlayerSealedPools` 保存完整真实印次、槽位、闪卡标记、种子、配置版本／指纹和生成器版本，参与权威状态哈希。默认构筑状态省略这些字段。

现开房间拒绝开发场景重置，防止场景替换清空池或改写种子；构筑开发场景保留现有行为。

快照采用 ADR 0001 的现有 `format/setCode/bestOf/sealedPool` 字段。本人只收到自己的卡包和卡池计数，所有返回集合均复制；对手池、种子、配置指纹不进入快照、提示和事件。观战回放明确禁用私有池投影，不依靠占位玩家编号来判断观战身份。恢复校验会检查卡池所属席位、种子、版本、卡包与计数一致性，并检查每个玩家／观战快照的格式和卡池是否符合其身份。从原始空房间重放入座命令重新生成卡池，最终权威哈希必须一致，不能拿最终帧反向制造起点。配置指纹改变时拒绝恢复，不用新配置重抽。

共享投影使用不可入座的空查看者身份计算观战可见性；`table.viewerPlayerId = "__spectator__"` 仅保留为展示标签，不参与权限判断。因此合法昵称恰为 `__spectator__` 的玩家仍能看到本人手牌，观战快照、公共事件来源和恢复校验始终按匿名身份隐藏其私有信息。OGN／SFD 真实六包开局、构筑开局、冷恢复与回放及既有来源隐私定向回归共 32/32 通过。

`SUBMIT_DECK` 和准备时复查都按卡组所属玩家读取私有权威卡池及房间 `bestOf`，不采信请求中的卡池字段。当前格式为现开时，实时请求和恢复日志的角色字段允许省略、`null` 或空字符串，仍拒绝错误类型与空白字符；构筑保持原有必填字段校验。准备复查他人的卡组时只返回通用中文错误，不返回其牌号。空白战场在现开正式开局时加入本次牌号解析表，随后使用共享物体、区域与战场流程。可空角色的开局和补抽见 ADR 0004。

本项接通房间内部入座、私有状态、投影、卡池约束的提交和核心开局。共享多局模型、先后手选择和逐局恢复见 ADR 0005；公开现开建房待局间卡组／战场约束齐备后开放。测试使用六包生成结果直接组出合法卡组，从原始空房间执行真实提交、双方准备、调度、各自首回合补抽、冷恢复、令牌重连和完整动作日志审计；不替代后续完整现开对局验收。

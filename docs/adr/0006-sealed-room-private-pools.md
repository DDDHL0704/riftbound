# ADR 0006：现开房间的私有卡池

2026-11-02，依据中国区[赛事规则](https://cdn.playloltcg.com/lol/2026/10/2026-10-10/0d5c26b5535345d48e1afafb3e2a0018.pdf) 602.1.a.1、602.4.a.1、602.4.b.2.a。每名玩家的六包由服务端在真实入座事务中生成，和席位一起提交到私有权威日志。写入失败不安装席位或卡池；同一玩家重复入座不重新生成。同步入座入口在现开房间转用相同事务流程。

房间配置使用 `MatchSessionOptions.ForSealed(setCode, bestOf)`，只接受统一配置中已开放的系列及 1／3 局制，并强制关闭无卡组准备、隐藏提交牌面。房间私有开局种子通过 HMAC-SHA256 的独立域、系列和固定席位派生各玩家种子；独立于对局洗牌消耗顺序，也不受玩家昵称影响。`PlayerSealedPools` 保存完整真实印次、槽位、闪卡标记、种子、配置版本／指纹和生成器版本，参与权威状态哈希。默认构筑状态省略这些字段。

现开房间拒绝开发场景重置，防止场景替换清空池或改写种子；构筑开发场景保留现有行为。

快照采用 ADR 0001 的现有 `format/setCode/bestOf/sealedPool` 字段。本人只收到自己的卡包和卡池计数，所有返回集合均复制；对手池、种子、配置指纹不进入快照、提示和事件。观战回放明确禁用私有池投影，不依靠占位玩家编号来判断观战身份。恢复校验会检查卡池所属席位、种子、版本、卡包与计数一致性，并检查每个玩家／观战快照的格式和卡池是否符合其身份。从原始空房间重放入座命令重新生成卡池，最终权威哈希必须一致，不能拿最终帧反向制造起点。配置指纹改变时拒绝恢复，不用新配置重抽。

本项接通房间内部入座、私有状态、投影和恢复。公开现开建房、卡池约束下的 `SUBMIT_DECK`、可空角色和空白战场的实际开局，仍在房间对局接入步骤完成；此时公开建房继续返回既有中文未开放提示。`bestOf = 3` 在本项只记录选择，多局生命周期由共享比赛模型接入。测试从真实空房间及席位日志执行冷恢复、令牌重连和完整动作日志审计，不代表完整现开对局验收。
